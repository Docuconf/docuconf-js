# Changelog

All notable changes to @docuconf/core are documented here. Entries after 0.1.0 are generated by
[release-please](https://github.com/googleapis/release-please) from Conventional Commit messages; see
[CONTRIBUTING.md](../../CONTRIBUTING.md).

## 0.1.0

First version of the code shared by the docuconf JavaScript SDKs, implementing spec `v1alpha1`. Tags:
`core-vX.Y.Z`.

### Features

* Contract writer, file input checks (TLS key pairs, CA bundles, keystores, config files), violations with stable
  error codes, Go durations, RE2 patterns and JSON Schema checks.
* Contract-first mode and the shared conformance runner.
* ESM and CommonJS builds.
