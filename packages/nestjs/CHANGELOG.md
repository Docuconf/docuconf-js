# Changelog

All notable changes to @docuconf/nestjs are documented here. Entries after 0.1.0 are generated by
[release-please](https://github.com/googleapis/release-please) from Conventional Commit messages; see
[CONTRIBUTING.md](../../CONTRIBUTING.md).

## 0.1.0

First version: typed configuration contracts for NestJS (`@nestjs/config` with a class-validator class),
implementing spec `v1alpha1`. Tags: `nestjs-vX.Y.Z`.

### Features

* Declarations from class-validator classes with docuconf decorators for what class-validator cannot express
  (descriptions, secrets, URL schemes, file inputs).
* `docuconfValidate` for `ConfigModule`: boot validation that reports every problem at once with stable error
  codes.
* Contract export with `toContract` and the `docuconf-nestjs export` CLI.
* The `nestjs` and `orders-nestjs` examples.
