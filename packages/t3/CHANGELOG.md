## 0.1.0

First version: typed configuration contracts for [T3 Env](https://env.t3.gg) with Zod 4, implementing spec
`v1alpha1`. Tags: `vX.Y.Z`.

### Features

* A `createEnv` wrapper and helpers (secrets, file inputs, list bounds including `itemMin`/`itemMax`) that keep T3
  Env's API.
* Boot validation of variables and file inputs that reports every problem at once with stable error codes.
* Contract export with `toContract` and the `docuconf export` CLI, for TypeScript and plain JavaScript (`.mjs`,
  `.cjs`) modules.
* The `t3` and `orders-t3` examples.
